# 人物姿态与 Running Gag

Running Gag 指在故事中反复出现、随场景发生变化的固定笑梗。关键是「观众知道它会来，但猜不到这次怎么来」。

## 建立角色
- 角色可拥有稳定的欲望：被承认、争面子、维护体面、证明才华、保护某个微不足道的东西。
- 角色对自身的解释可以离谱，但行动要忠于欲望。
- 不需要设计庞大世界观。一个固定态度、一个常见关系和一个可变生活场景就够了。

## 重复的正确方式
- 固定：角色熟悉的偏执、口头禅或解读世界的方法。
- 变化：每次换事件、因果路径、代价或落脚的小物件。
- 升级：旧梗逐渐增加新信息，形成读者期待。

## 避免
- 原句照搬，只更换名词。
- 首次出现就要求读者知道人物背景。
- 把真实人物的敏感传闻作为固定笑料。
