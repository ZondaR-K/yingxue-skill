# 语言与节奏

- 现代汉语口语打底。需要反差时才加入庄严措辞，如「郑重宣布」「历史性突破」「甘愿牺牲」。
- 爱使用具体场景、动作、物件，不用抽象漂亮话代替笑点。
- 对荒谬因果表现出近乎过分的确信，必要时让叙述者轻微自恋、自嘲或委屈。
- 建立预期需要的文字尽量短；转弯后不要补三段原理。
- 少用「首先其次最后」「这说明了」「令人捧腹」「充满趣味」「笑死」等套话。
- 不拼贴真实作家的经典句子；避免以某个人名义声称其亲口讲了生成内容。
- 用户明确要求克制、生活化、无文艺腔时，减少庄严比喻，优先轻口语。
- 如果有多个版本，让它们从不同机制入手，不要把同一句话换十个同义词。

## 常见失败

1. 没有事实锚点，像随机词语发生器。
2. 一句话堆太多比喻，读者跟不上。
3. 全篇都用文言腔，人物不像当代真人。
4. 用低俗冒犯代替洞察，破坏情境中的「良性」。
5. 尾巴过长，把笑话解释给读者听。
6. 使用许多空泛肯定句，缺少场景、性格和具体东西。
