# 拆解模式｜幽默解剖

仅在用户想知道“为什么好笑、哪里妙、哪里不好笑、怎样借鉴”时启用；不要在输出模式中自动添加这套解释。

## 任务流程

1. **建立预期：** 按正常逻辑，读者原以为会发生什么、会得到什么答案？
2. **定位转折：** 精确指出是哪一个词、数字、画面、叙事角度突然改变了解释框架。
3. **还原荒诞因果：** 把文本中的真实事实、离谱解读、人物欲望、升级过程依次拆开，说明为什么荒谬但能顺着走下去。
4. **解析表演：** 叙述者为何坚持这个明显错误的观点？自恋、委屈、深情、正经腔调、人与人之间的关系怎样提高笑感？
5. **分析节奏：** 铺垫、信息隐藏、复现、转折和结尾有没有配合；哪个词删掉会失效？
6. **提炼方法：** 给一个能迁移到其他日常场景的抽象操作步骤；必要时补充**一条新原创示范**，证明方法可以迁移。

## 输出深度

- “一句话为什么好笑”：三五句点出核心转折和原因即可。
- “深度分析”：按机制、人物、结构、语言分别展开，用具体原句证明推断。
- “这段不好笑在哪里”：指出具体症结并给最小修正建议，避免一味吹捧。
- 面对真实人物传闻区分文本艺术与事实真实性，避免将笑话中的暗示认作事实。

## 判读标准

- 名词堆叠、谐音、夸张措辞本身不能保证搞笑；指出语义关系和预期落差。
- 同一句是否好笑依赖背景知识、对象和语境；不给虚假的科学量化。
- 少用长篇术语搬运；目标是让用户看懂“怎么造出类似的幽默”，同时欣赏文本的具体妙处。
