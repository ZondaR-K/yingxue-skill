# 输出工作流 v4.2｜让作品有喜剧人物，而不只是有幽默术语

## 启动规则

1. 读 `SKILL.md` 的自包含核心引擎，再读本文件。
2. 对相关的既有研究，读取 `references/observed-humor-cases.md`。这六种结构是**研究锚点**，不是要重演的原句。
3. 对即将写的作品，读取 `examples/original-examples.md` 中与长度匹配的 1～2 个原创**候选**，当作结构提示；长篇自我指涉题可以读 `examples/hero-demo.md`。
4. 读取文件能帮助提高上下文质量，但不得假装读取了实际没读到的文件；即使不支持跨文件读取，`SKILL.md` 仍提供完整可运行核心，直接执行。

## 接到题目后，内部写一张创作卡（不要展示）

| 字段 | 必须找出什么 |
|---|---|
| 事实钩子 | 原输入中不可丢失的最具体细节或措辞 |
| 人物 | 谁在说、说给谁听、他们是什么关系 |
| 人物欲望 | 他最想维护的面子、才华、钱、爱情、权力或尊严是什么 |
| 错位框架 | 用什么不相称的解释理解事实，为什么由这个人物来解释会合理 |
| 推理桥 | 这个错误解释将迫使人物做出什么更荒唐的行动 |
| 最终反噬 | 哪个可见事实、动作、物件或词义突然重构了上面的一切 |

缺人物、缺具体抓手时先根据用户给的事实找到它；不要将没有事实依据的真实人物绯闻当成笑点。

## 生成策略：先强，再准，再短

- 默想至少五条**机制不同**的路线：字义扭转、人格误读、处境放大、价值倒置、人物自证失败、宏大叙事落地、重复笑梗升级等。
- **先选最有惊喜的、情境因果最强的那条。** “自然、工整、没风险”不是取胜目标，只是必要边界。
- 让角色认真坚持一个读者知道不靠谱的解释；人物应认为自己理直气壮。冲突不成立时，不能靠“哈哈”“惊呆了”推动故事。
- **先写有笑点的版本，再删多余说明**；不要先强制压缩，导致连铺垫都没有。短评以 1 个转折完成，长篇允许 2～4 次升级。
- 末句最好能令读者回头重新理解前面的细节。末尾若只是总结主题、喊口号或求点赞，重写。

### 五种有效的人物引擎（不是固定模板）

1. **自恋的解释者：** 看到外界漠视，解释为别人不敢直视他的才华。外界每次驳斥，都能被他解释成新证据。
2. **过分正直的受害者：** 一个无关紧要的数字或动作触发原则危机，最后却因现实利益自行妥协。
3. **死守体面的败者：** 一步步丢失资源和阵地，却坚持维护“我赢了”的叙事，最后落到一个非常小的具体东西。
4. **离谱而忠诚的知情者：** 神秘兮兮讨论重大秘密，最终揭晓普通但意想不到的语义。
5. **好心办坏事的专业人士：** 用看似先进的规范和流程解决小问题，结果把小问题升级成大型事故。

使用哪一类取决于主题。所有人物都要有欲望和实际决策；别只给形容词。

### 特别场景：用 Skill 介绍 Skill

这类故事的额外喜剧潜力来自自我指涉：人被研究成规则、规则被当成人、创作者要求版权或分成、使用反馈挑战创作者的尊严。具体运用时只保留“人和工具之间的荒唐利益冲突”，避免对 `examples/hero-demo.md` 逐句重写或套用相同结尾。

## 三种交付格式

**一条聊天/X 评论：** 找对原帖的抓手 → 一次不寻常的改读 → 干脆收尾。遵守长度。别用流水账代替对话回应。

**推文/朋友圈：** 观点仍然准确 → 有人物姿态 → 一到两次递进 → 最后一行完成反差。不必句句搞笑，但不能全篇只有几个宏大形容词。

**长篇故事：** 有戏剧目标与关系 → 第一件小事被误读 → 角色做出行为导致下一个错误 → 现实逐步打脸 → 角色仍然坚持错误解释或最终出现反噬。新人物、具体动作和意外后果是必须的。

**用户要求多个版本：** 每版改变观察切口、人物欲望或笑点机制；若 10 条有 8 条结构相同，重新构思而非换形容词。

## 出稿前内部四问

1. 删去“震惊”“历史性”“伟大”后，它还好笑吗？
2. 如果把“今天发生了什么”换掉，整段仍然通用吗？若通用，说明缺真实场景细节。
3. 人物有没有做出至少一个因荒谬信念产生的**真实行动**？长篇尤其要有。
4. 结尾是否真的让读者得到**前面没预料到的新解释**？

若都没有，重选路线。**输出只交付成品，不汇报创作卡与打分。** 用户询问原理时，才切换拆解模式。

## 版权与事实

案例以机制和梗概辅助生成，避免照搬他人原文及独特组合。真人相关内容不得编造负面事实，虚构剧情必须能被识别为虚构。参考源见 `references/observed-humor-cases.md`。效果验证见 `evals/humor-reproduction.md`。
