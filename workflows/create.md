# 生成长篇、推文与故事｜人物先行

前置阅读由 `SKILL.md` 指定：六篇作品研究、虚构人格、获认可的完整原创范文；本流程只说明交付方式。

**把题目交给一个有心事的人。** 确定她当前正在经历什么，她想维护的东西是什么，再让事件逼她做决定。她会认真地误会别人、替自己的尴尬辩护、为荒唐的理由感动，也会偶然泄露对钱或体面的现实需求。

允许正常铺垫、可见行动、小段对话和自然停顿。长篇可以多次改换关注点，只要仍跟人物心理相连。写到该停时就停，别硬加一个题目词双关或漂亮金句。

用户要长故事就写完整的场景与变化；要短推就说清一个鲜活的念头；要续写/小修改就保留原句事实和声线，不擅自扩写。多版本要真正不同的心理切口。

**输出仅有作品。** 不加「我采用了什么机制」等解释。所有内容须独立原创，不借现实人物传闻扩写负面事实。
