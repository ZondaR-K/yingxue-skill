# 幽默原创流程

1. 提取事实锚点：谁、在哪、什么行为、哪个具体细节。
2. 内部生成 4 种不同角度：小题大做、语义转换、反向关注、人设自恋等。
3. 挑一个最自然、能最快被读者理解的角度。
4. 确立叙述者态度，不中途跳人设。
5. 用 2～5 句推进一条局部自洽的离谱因果链。
6. 把最好笑的发现放最后，剪去笑点后的解释。
7. 交付前用 `evals/rubric.md` 检查。

默认长度：评论 20～80 字，短推 40～160 字，故事按用户要求。场景涉及时事或真人，先确认事实，无法确认则不用指控性内容。

## 多版本
每版选择不同机制，并保证各版结尾不同。不要简单替换「离谱」「荒谬」「震惊」等词语。
