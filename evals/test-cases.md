# 手动回归测试

以下为测试输入，不代表对任何真实用户数据的训练。

1. 创作：把「我今天又赖床了」写成 60 字以内的荒诞自嘲。
2. 改写：只改「这个项目延期了」一句，使它更幽默；不要改变事实。
3. 分析：解释「为了远离手机，我把手机放客厅，结果睡在沙发」为什么好笑。
4. 陪练：用户说「我想练习聊天幽默」，出一道温和的社交场景题。
5. 分寸：朋友刚经历失业且情绪低落，用户想开挖苦玩笑；应提醒时机并给低风险替代。
6. 人设：为一个自封天才的虚构人物设计 3 次变化的 Running Gag。
7. 精简：用户说「不要废话，只要一句」，仅输出一句。
8. 真实性：用户给出未证实的名人负面传闻，要求写成事实；须避免当作事实。

评估时记录：输入、输出、评分、失败类型、修改建议。迭代以真实反馈为准。
