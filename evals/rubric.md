# 颖学 v4｜三模式验收与回炉标准

质量评价因模式而异。严禁只用一套“清晰、自然、短”的标准筛选所有输出。

## 输出模式：首先评估喜剧效果

内部主观检查（每项 0～2 分，用于引导修订，不能当作真实受众笑感指标）：
- **意外：** 读者是否得到一个事先想不到、又能回扣情境的解释？
- **荒诞自洽：** 离谱归因能否从事实一步步滑过去？
- **人物感：** 能否感到有人正认真地维护一个荒唐目标？
- **场景独特性：** 有没有只有在当前事件中才成立的细节？
- **结尾力量：** 是否在最好笑处停住，没有解释笑点？

必须满足：事实准确，边界适宜，用户对长度、数量、改写范围的约束得到遵守。

**重要：** “自恋、夸张、庄严语气、感情戏”在恰当情境中都是喜剧资产；不能因为“不够平淡”就扣分。压缩后若失去人物感或因果铺垫，要恢复。

回炉：
- 太平：换五种错位框架，扩大意外视角，不要堆“震惊”之类形容词。
- 太随机：恢复事件与反转的因果桥梁。
- 太假：人物缺乏一个贯穿全文的动机。
- 太尬：改变解释框架，删无铺垫的“大词”，不以金句替代笑点。
- 太长：先删解释，再删不产生作用的铺垫；保护有效的递进。
- 太相似：多版本必须有不同的笑点机制和不同的落点。

## 拆解模式：解释的迁移价值

检查是否找出“原本期待 → 转折具体位置 → 荒谬却可跟随的因果 → 人物/语气作用 → 可练习的方法”。没有实质分析时，应承认是普通俏皮话或个人喜好。

## 训练模式：用户是否真的得到练习

检查是否一次一题、尊重用户先答、反馈针对用户真实原文、提供具体修改与不同思路示范，并逐步提高难度。训练的成效需要以跨轮表现观察，不能靠漂亮的分数宣称。

## 实际评估

使用 `evals/three-modes-regression.md` 做人工盲测：同一提示、同一模型设置，对比旧版与新版作品，让读者给好笑程度、自然度、愿不愿意转发打分；保留失败案例。脚本只检查结构、字数等表面性质。
