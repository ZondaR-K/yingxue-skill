# Contributing

Suggestions and PRs welcome: provide a problem example, expected behavior, proposed mechanism and whether the example is original or licensed. Add regression cases to `evals/dataset.jsonl` where useful. Avoid submitting identifiable private chats or allegations about real people. Never represent synthetic example ratings as actual evaluation evidence.

Run `python -m unittest discover -s tests -v` before submitting. For model-based claims include model name/version, settings, exact task data, sampling plan, anonymized human ratings and limitations.
